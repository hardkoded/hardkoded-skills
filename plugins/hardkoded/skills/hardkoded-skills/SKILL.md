# hardkoded-skills

## Purpose

Help the user brainstorm random software project ideas.

## Use this skill when

- the user wants a random app, game, tool, or startup idea
- the user asks for inspiration
- the user wants multiple concepts to choose from

## Instructions

When this skill is used:

1. Ask for missing constraints only if they are important.
2. Generate 5 ideas unless the user asks for a different number.
3. Keep each idea short and practical.
4. For each idea include:
   - a name
   - a one-line summary
   - why it is interesting
   - the first small step to build it
5. Favor ideas that can be prototyped quickly.

## Output style

- clear
- energetic
- concise

## Example request

"Give me a few random side-project ideas for developers."
